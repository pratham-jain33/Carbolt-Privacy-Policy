# Carbolt — Privacy Policy

The published privacy policy page for the Carbolt Chrome extension, hosted as a static site on GitHub Pages.

**Live page:** https://pratham-jain33.github.io/Carbolt-Privacy-Policy/

## Why this repo exists

The Chrome Web Store requires every extension to link a public privacy policy. This repo hosts Carbolt's, as one static page that anyone can read without an account.

## Contents

- `index.html` — the policy page.
- `privacy-policy.css` — the page styles.
- `logo128.png` — the Carbolt logo shown on the page.

## Features

- One static page, publicly readable without an account.
- No JavaScript. What you see is the whole policy, in one page.

## Tech

Plain HTML and CSS. No build step.

## Installation

Nothing to install. The page is hosted on GitHub Pages from this repo; to preview a change locally, open `index.html` in any browser.

## Usage

Open the live page above. To preview a change locally, open `index.html` in any browser.
